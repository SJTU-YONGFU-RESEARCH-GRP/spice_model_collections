# ICS55 / ICsprout55 — model availability

The source-pinned v1.10.103 release does **not** provide transistor SPICE model
cards. Its CDL netlists describe connectivity and cannot establish transistor
electrical behavior, corners or simulator support. No electrical model snapshot
or simulation pass is claimed here. The source identifiers are in [SOURCE.json](SOURCE.json).

CDL references remain available in the original upstream release. This update
does not copy complete standard-cell/IP netlists into the electrical model
collection. The uncommitted local reference material was preserved separately.
