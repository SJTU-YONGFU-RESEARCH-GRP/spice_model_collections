# GT3 (3nm GAAFET Nanosheet)

## Technology Overview
- **Node:** 3nm Gate-All-Around Nanosheet FET (GAAFET)
- **Model Standard:** BSIM-CMG (Level 72 / Level 110)
- **Origin:** Georgia Institute of Technology
- **Supported Simulators:** HSPICE, Spectre, Xyce
- **Devices Available:**
  - `nmos_rvt` / `pmos_rvt`: Regular threshold voltage GAAFET
  - `nmos_lvt` / `pmos_lvt`: Low threshold voltage high-speed GAAFET
- **Model Files:**
  - `hspice/gt3_rvt.mod`
  - `hspice/gt3_lvt.mod`
